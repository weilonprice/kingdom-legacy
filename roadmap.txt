GUIDING RULES
--------------------------------------------------------------------------------
  - Keep the game playable at the end of every milestone.
  - Systems first, art later: placeholder shapes until a system is locked in.
  - Data-driven: new buildings/units/enemies should mostly be new entries in
    a defs file, not new code.
  - Prove each milestone with tools/verify (real input, screenshots; see
    .claude/skills/verify-kingdom-legacy) plus headless smoke tests for long
    simulations, before playtesting by hand. Add a feature file + scenario
    for new player-facing features.
  - Spend PixelLab generations only on assets whose size/role is final.

M1 — FOOD & GROWTH                                    [DONE]
================================================================================
  Systems
  [x] (M) Generic "produce" work type: worker fetches input from storage,
          works work_time at the building, hauls output to storage
          (building_defs keys: work, input, output, work_time)
  [x] (S) Output space reservation so full storage can't deadlock a chain
  [x] (M) Storage capacity limits per category (materials / food)
          NOTE: stock is pooled kingdom-wide; villagers still walk goods to
          the nearest storage accepting that category. True per-building
          inventories are deferred (see BACKLOG).
  [x] (M) Workers fetch inputs from storage, deliver outputs to storage
          -> villager.gd
  [x] (S) Food resource type(s): wheat, flour, bread, fish
          -> scripts/data/item_defs.gd

  Buildings
  [x] (M) Farm: tills up to 8 field tiles around it, plant -> grow (45s)
          -> harvest 3 wheat (new FIELD terrain with 3 growth visuals)
  [x] (S) Mill: wheat -> flour
  [x] (S) Bakery: flour -> bread
  [x] (S) Fisher's Hut: must be placed next to water -> fish
  [x] (S) Granary: food-only storage
  [x] (S) Well: placeable, shows coverage radius (no effect until M5)

  Population
  [x] (M) Food consumption: each villager eats periodically from storage
  [x] (S) Growth gated by food: no new villagers if food stock is 0
  [x] (S) Starvation: villagers leave the town after X time without food
  [x] (S) HUD: food total + "days of food" estimate

  UI
  [x] (M) Building inspector panel (click a building): workers, inventory,
          status ("waiting for flour", "no road", "storage full")
          -> scripts/ui/building_panel.gd
  [x] (S) Categorized build menu tabs (Roads/Housing/Resources/Food)

  Done when: a town of 20+ runs a farm->mill->bakery chain and grows only
  while bread keeps up; inspector shows why a building is idle.
